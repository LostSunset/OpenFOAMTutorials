# Extra and realistic OpenFOAM Tutorials
The repository includes all OpenFOAM tutorials created by Tobias Holzmann and are available on the website https://Holzmann-cfd.com

The 33 tutorials are based mainly on the OpenFOAM version from cfd.direct (https://OpenFoam.org) while a few others are based on the OpenCFD OpenFOAM version (https://OpenFoam.com).

Since cfd.direct removed the AMI and ACMI approach completely, some tutorials were converted to the OpenCFD version in order to keep them in the history line.

# Important information
All tutorials given in the repository are identical to the one given on my website https://Holzmann-cfd.com
However, based on large geometry and background files and lack of LFS (large-file-tracking) of GitHub (only 1GB storage + 1GB traffic), I removed all geometric data from the repository. Hence, you need to download the full case (including all geometric data) from my website.
